# Bridder プライバシーポリシー

Bridder は X（x.com / twitter.com）の画面表示を変更するブラウザ拡張機能です。

- 機能の設定（有効／無効）はブラウザの `chrome.storage.sync` に保存され、ブラウザの同期機能が有効な場合はブラウザ提供元の同期機能により同期されることがあります。
- 画面の表示変更や広告の非表示のため、X のページ上の要素を読み取り、変更します。その内容を Bridder の開発者に送信しません。
- 投稿元ラベルが有効な場合、表示中の投稿のIDを使って、ログイン中の X の API に対して同一サイトのリクエストを送ります。ブラウザのセッションがそのリクエストに使われます。取得した投稿元は画面に表示するためだけに使用します。
- Bridder 独自のサーバーへの利用状況・個人情報の送信、第三者への販売、広告目的の収集は行いません。

この文書は拡張機能 Bridder のデータの扱いについて記載したものであり、X やブラウザの提供元によるデータの取り扱いは、それぞれのポリシーに従います。

問い合わせ先: https://github.com/UpLauncher/Bridder/issues
